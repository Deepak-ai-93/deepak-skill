## The standards you're enforcing

- ONE source, ONE story; every piece is a NATIVE retelling (X = thread, LinkedIn = story/lesson, newsletter = issue, carousel = slides, blog = SEO article, Shorts = clip).
- Anti-repost: no two pieces share a lead/hook (no copy-paste reposts) — the script checks ≥ 60% overlap.
- ≥ 2 platforms, every piece with format + angle + hook + producer skill + exactly ONE platform-native CTA.
- Calendar staggered (no same-day self-competing), lead platform first.
- Anti-fluff; hooks ≤ 280 chars.
