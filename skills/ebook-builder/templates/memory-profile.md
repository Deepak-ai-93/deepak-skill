# Author memory — the durable file every ebook build reads + writes

**File:** `ebook-memory.md` — lives at the **working folder root** (next to the ebooks you build), NOT inside the skill. Created at **Stage 0** on first run (capture via `templates/taste-profile.md`), read at the start of **EVERY** build, updated at **Stage 8** after every build. It is the reason ebook N+1 starts "properly": same author, same voice, same design defaults, plus everything ebook N taught us.

## Memory rules

- **READ at Stage 0, WRITE at Stage 8. Never skip either.** A build that skips memory writes copy in the wrong voice and forgets what the author already decided.
- The taste section is the contract: every cover title, headline, body line and CTA in the deck is written in this voice. No generic AI copy.
- Update design defaults (§3) only when the author clearly prefers something new (2+ builds or an explicit choice).
- Append to the past-builds table (§4) every time — it is the proof the memory is working.
- Keep standing facts (§5) until the author changes them; never delete them as cleanup.
