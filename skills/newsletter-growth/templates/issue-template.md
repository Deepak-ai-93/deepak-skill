# Issue template — reference for newsletter-growth

The issue is a micro-story: subject opens a loop → first line hooks → the middle raises stakes → payoff delivers the lesson → value receipts prove it → ONE ask → growth plug.

## Subject-line formulas (pick ONE, ≤ 60 chars)

| Formula | Mechanism | Template | Example |
|---|---|---|---|
| **Curiosity gap** | Hide the payoff | "The [thing] nobody tells you about [X]" | "The button that cost us $12,400" |
| **Number / list** | Structure + tease the outlier | "[N] [things] — #[K] is the one that hurts" | "3 pricing mistakes — #2 is the expensive one" |
| **How-to / result** | Promise a concrete outcome | "How I [result] without [common trap]" | "How I tripled revenue per visitor in 30 days" |
| **Pain / loss aversion** | Name the pain, promise relief | "Stop [pain]. Try [one move]." | "Stop losing trial users at signup" |
| **Story tease** | Start mid-scene | "It was 11pm when the invoice arrived…" | "It was 11pm when the invoice arrived" |
| **Pattern interrupt** | Absurd-but-true stat | "[stat] — and nobody talks about it" | "87% of founders price by feel. It's a lottery." |

## The issue skeleton

```
Subject: {formula line} (≤ 60 chars)

## The open (hook)          — first line opens a loop: a moment, a number, a question.
## The stakes (rising)      — the twist/mistake/stakes. What was on the line?
## The payoff               — the lesson the hook promised. The "aha".
## Value — the receipts     — 2–4 bullets: numbers, examples, named people, steps.
## One ask                  — EXACTLY ONE: reply / forward / click. Nothing else.
## Growth plug              — EXACTLY ONE: "forward this to a founder", "share the link".

Word count: 350–900 · Read time: ~2–4 min
```

## Rules

- **Subject ≤ 60 chars** and matches the issue's promise — bait that isn't paid off kills opens next week.
- **First line opens the loop.** If the first line could start any newsletter, it's not the hook.
- **One CTA + one growth plug.** Two asks = no asks. The growth plug is the ONLY forward/referral ask.
- **Receipts beat adjectives.** Every value bullet has a number, an example, or a name.
- **Fluff rule:** every section either raises the question, raises the stakes, or pays off.
- **Serialization:** end on a tease of next week ("next issue: the teardown with the numbers") so the loop carries over.
