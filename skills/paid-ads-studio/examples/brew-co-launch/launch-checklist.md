# Launch Checklist — Brew & Co Tumbler Paid Launch

Everything below is **manual copy-paste** into the platform UIs. The skill never touches your ad account.

## Pre-flight (day 0)

- [ ] Generate + upload reference Images (hero, lifestyle, detail) to Flow Ingredients / Midjourney `--cref` / Flux
- [ ] Generate the 3 video ads + 4 image ads from `prompts.md` (keep the same Ingredients for every prompt)
- [ ] Export at platform specs: images ≤5 MB; videos 1080p H.264/AAC
- [ ] Add logo + any fine print in post (generative text rule: ≤3 words native)
- [ ] Landing page live + tracked: Meta Pixel + CAPI (high EMQ) · Google tag (or GA4/gtag) · consent mode on
- [ ] Test a real purchase end-to-end → confirms both platforms see the conversion event
- [ ] Re-verify the compliance checklist is still current (`guidelines-checklist.md`)

## Meta launch (day 1)

1. Ads Manager → Create → **Sales** → Advantage+ Shopping campaign
2. Set controls (US, 18+) + suggestions (site visitors, engagers, lookalike seed)
3. Budget: CBO **$25/day** (50% ramp); placements automatic
4. Ad set: add 3-5 creatives (Reels 9:16 + hero square + lifestyle 4:5 + flat-lay)
5. Copy: paste `copy.md` META-FEED / META-REELS primary text + headlines + description + CTA
6. Bidding: Highest volume (weeks 1-2)
7. Publish → confirm delivery, no policy issues flagged

## Google launch (day 1)

1. **Demand Gen** campaign: $9/day (50% ramp) · audience signals: customer list + site visitors · add Reels video + 4:5 image + 1.91:1 flat-lay · paste copy.md GOOGLE-DISPLAY assets · set AI label
2. **PMax** campaign: $6/day (50% ramp) · asset group: 4 headlines + 5 descriptions from copy.md GOOGLE-SEARCH/DISPLAY · square + landscape + portrait images + 15s video · AI label on
3. Confirm both campaigns show "learning" status

## Days 2-3

- [ ] Hold budgets at 50%; no targeting changes; no pausing
- [ ] Check conversion tracking fired on real purchases (not just test)

## Day 4 → end

- [ ] Ramp to full budget (Meta $50 / Google $30) — only if ROAS trend is ≥1.0×
- [ ] Follow `cost-plan.md`: kill at CPA > $100 after $80 spend on an asset; scale +20% every 3 days at ROAS ≥ 2.0×
- [ ] Re-forecast after week 1 with real CPM/CTR/CVR (`--overrides`)
- [ ] Refresh creatives every 2-3 weeks with the `Edit:` variants
- [ ] Log results weekly; compare against `forecast.md` scenarios
