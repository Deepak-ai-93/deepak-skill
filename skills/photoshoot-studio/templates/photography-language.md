# Photography Language — camera, lens, lighting, grade

The vocabulary that turns "professional photo" into a real photoshoot. Pick ONE item per row and be specific. Read the SKILL.md § Photography language first.

---

## The 6-part prompt formula

Every generation prompt = `Style + Subject block (VERBATIM) + Pose/placement + Setting + Craft block + Grade token`, joined as sentences. The script assembles this automatically — this table is for writing the PLAN fields.

---

## 1. Photographic style (shot.style) — the genre/mood

| Person shoots | Product shoots |
|---|---|
| Editorial fashion photography | Commercial product photography |
| Beauty / cosmetics close-up | Hero product shot (e-commerce) |
| Candid lifestyle photography | Lifestyle product photography (in-use) |
| Environmental portrait | Packaging / retail photography |
| Fine-art studio portrait | Floating / levitating product shot |
| Street-style fashion photography | Detail macro photography |

## 3. Aperture

| Setting | Effect |
|---|---|
| f/1.4 – f/2.8 | shallow depth of field, creamy bokeh, isolated subject |
| f/5.6 | balanced sharpness + some context |
| f/8 – f/11 | edge-to-edge product sharpness (hero/packaging shots) |

## Common anti-drift rules (what NOT to write)

- Never re-list the subject's features in the shot fields — the subject block already does it. Shot fields only add pose/setting/lighting.
- Never add a second grade — one token per shoot.
- Avoid "8k, ultra-realistic, masterpiece" filler — it pollutes prompts; the craft token already covers quality.
- For product text/labels that must read exactly, put the words in quotes inside the setting field (e.g. `a label that reads "PURE BOTANICALS"`).
