# Engagement Protocol — the first-60-minutes rule

Every 2026 algorithm reads the first 60 minutes after a post as a diagnostic:
early engagement velocity decides whether the post reaches its second-tier
audience. This is the highest-leverage hour of Dan's day. It is scheduled,
not optional.

## The first-60-minute protocol (after EVERY post)

| Time after post | Action |
|---|---|
| **0–10 min** | Reply to every comment that lands. Reply with a follow-up question — one reply that asks something doubles the thread depth. |
| **10–30 min** | Comment with ONE added insight on **5–10 niche accounts** (targets below). Never filler — add a data point, a question, or a take. |
| **30–60 min** | Answer every DM (the "PROTOCOL"/"START" DMs convert later). Share the post once via Story/quote with an insight. Log the post's early numbers in metrics.md. |

Daily budget: **30–60 min/day**, split as 2–3 blocks (morning post window,
lunch, evening). Total plan load = posting (≤ 1 h/week) + engagement
(3.5–7 h/week) — fits a 5 h/week budget on light days, 8 h on heavy.

## Comment targets (build this list on day 1)

- 3 competitors (reply with an insight, never a pitch)
- 3 busy-professional / HR-adjacent accounts (the audience, not the niche)
- 2 fitness-science accounts (add credibility by adding real data)
- 2 industry peers (mutual support, real conversation)

## How to comment (the rule that keeps it honest)

1. Read the post. 2. Add ONE thing it missed: a stat, a client result, a
   counterexample, a question. 3. Sign with substance. Banned: any comment that
   adds zero insight — filler ("💯", "This", "DM'd") never passes the bar.

## DM / CTA handling

- **"PROTOCOL" comment replies:** DM the framework within 24h + one
  qualifying question ("What's your current training schedule?").
- **"START" DMs:** answer within 24h, one call-to-book link, no pressure copy.

## Weekly cadence for the engagement blocks

| Platform | Daily engagement | Where |
|---|---|---|
| Instagram | 15–20 min | Reply to comments, comment on 5 targets, answer DMs |
| X | 10–15 min | Reply to every reply, quote 1–2 posts with insight |
| LinkedIn | 10–15 min | Comment on 3–5 targets (the first-hour lever) |
| YouTube | 5–10 min (upload days) | Reply to comments, pin a comment with a question, run the weekly community-poll |
