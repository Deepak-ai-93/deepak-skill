# A/B test — which thumbnail wins the click?

**Video:** "3 Pricing Mistakes That Cost You Revenue" (SaaS / B2B founders niche)

## The test

| | Variant A | Variant B |
|---|---|---|
| **Execution** | Founder realization face, warm lamp, downward revenue chart | Split screen: cluttered page vs clean one-price page, hand pointing |
| **Overlay** | "the mistake that costs $12k" | "your way vs mine" |
| **Emotion** | uneasy realization | curiosity + relief |
| **Why paired** | Emotion-led (relatability) vs structure-led (comparison) — the two most different executions | |

**Rules (non-negotiable):**
- **Title stays identical** across both — only the thumbnail changes.
- Same publish time, same promotion, one variable at a time.

## Window

- **Duration:** 2 weeks **or** until each variant passes **1,000+ impressions** — whichever comes second. (Small channels: 100 impressions is noise; don't call it early.)

## Judging (benchmarks: see templates/ctr-benchmarks.md)

| Outcome | Decision |
|---|---|
| B ≥ 15% relative lift over A, 1,000+ impressions each | **Winner** — ship B, then test B vs a new variant |
| Lift < 15% or impressions < 1,000 | **Keep testing** — pick a more different execution |
| CTR up but retention/session time down | **Clickbait mismatch** — revert; the thumbnail over-promised |
