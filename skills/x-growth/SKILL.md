# skill: x-growth

**Name:** X Growth — fast growth content planning + daily posting for X/Twitter
**Description:** Turns a niche + a growth goal into a **ready-to-run X growth pack**: `content-plan.md` (goal + KPIs + 3+ pillars + daily cadence + engagement schedule + day-7 review) + `posts.md` (a full week of drafted posts in the **top-creator format** — 500–800 char micro-essays: hook line ≤ 100 chars → story/context → bullet points → payoff → CTA, hook/value/story/proof/cta/loop mix, every constraint enforced by `post-writer.mjs`) + `x-audit.md` (the audit harness output). **Zero hashtags, always** — X growth is copy-first; the script fails any post with a `#`. Built for creators who want followers and attention FAST — the week is the series, the replies are the growth.

---

## Storytelling + addiction rails (the universal contract — read before anything else)

Every deliverable this skill produces must tell **ONE micro-story** and engineer **rewatch**. These rails are the SAME contract every video/image skill in this repo follows — apply them to every beat, post or clip before it ships.

**Applied to X growth:** each single post IS a micro-story — the first line opens the loop (the hook), the middle escalates ("and then…"), the last line pays off and converts (CTA/loop). The open loop is what stops the scroll; the WEEKLY MIX (hook → value → proof → CTA) is the series that turns a viewer into a follower — fast growth is serialization, not one viral post.

### The story spine (all four beats, always)

| Beat | Rule |
|---|---|
| **Open loop (hook, 0–3s)** | The first line of every post opens an unresolved question, tension or promise the brain must see closed. No intro, no "hey guys", no generic opening. |
| **Rising tension** | The post escalates before it lands: new stakes, a twist, a pattern interrupt, an "and then…". Never just fills space. |
| **Payoff** | The loop closes by the last line with the "aha" the hook promised. A loop opened and never closed kills trust and rewatch. |
| **Loop ending** | The last line seeds the next post or the account ("Part 2", "Next week", "I'll post the numbers") or chains into the CTA. |

### The addiction levers (use ≥3 per plan)

| Lever | Mechanism |
|---|---|
| **Curiosity gap** | The open loop the brain must close (Zeigarnik effect — unfinished tasks nag). |
| **Serialization / cliffhanger** | The WEEK is the series — the mix chains posts so the audience returns daily and follows for the next installment. |
| **Variable reward** | Payoffs land on a beat the reader can't predict — reveals, verdicts, twists. |
| **Pattern interrupt** | A contrarian take or absurd-but-true stat exactly where attention dips. |
| **Relatability / self-recognition** | "That's me" moments — the reader stops to see their own life, then follows or saves. |
| **Commitment bait** | A clear, specific CTA (follow / save / DM / link) — an engaged reader is a returning reader. |

### The fluff rule

Every post either **raises the question**, **raises the stakes**, or **pays off**. If a post can be deleted without losing the week's story, delete it.

## The quality bar (non-negotiable — read before anything else)

| Rail | Rule |
|---|---|
| **ZERO hashtags (the #1 rail)** | A single `#` in any post fails the plan (`post-writer.mjs` + `audit-x.mjs` exit 1). X growth is copy-first — hashtags are noise and read as spam. No exceptions, no replies with tags either. |
| **Top-creator post format** | Every post is a **500–800 char micro-essay**, exactly like the accounts that actually grow: **hook line ≤ 100 chars** (opens a loop) → story/context → **≥ 2 bullet points** → payoff → CTA, with **line breaks** (≥ 3 lines — a wall of text fails). Under 500 chars = too thin to rank; over 800 = truncated payoff. |
| **One micro-story per post** | Every post is complete alone: loop opened in the first line → paid off by the last line. No "I'm going to talk about", no hello posts, no "Day 1 of sharing…". |
| **The week is the series** | The post mix chains across the week: ≥ 1 hook post + ≥ 1 value post + ≥ 1 story/proof post + ≥ 1 cta/loop post, every pillar fed. A random feed doesn't grow; a series does. |
| **3+ live pillars** | The plan runs on ≥ 3 content pillars, each fed by real posts — no dead pillar debt. |
| **Anti-fluff + no bait spam** | No fluff words (unlock, game-changer, elevate, …), no "RT if you agree" / "tag someone" / follow-bait spam. |
| **Growth plan, not a wish** | The plan ships goal + KPIs + daily cadence + engagement schedule + a day-7 fix loop — fast growth is measured weekly and pivoted, not hoped for. |
| **Audited before delivery (the harness)** | Stage 6 is a harness, never a self-check: `audit-x.mjs` runs the automated checks (posts, 500–800 window, hook lines, format, ZERO hashtags, roles, mix, pillars, plan sections) → a FRESH x-auditor subagent scores growth-plan worthiness (/50, ≥ 35 = worth running) → fix loop until signed **PASS** in `x-audit.md`. |

## Workflow (6 stages)

### Stage 1 — Analyze the brief (ask ≤3 questions if vague)
Extract: **niche** (one, not three) · **growth goal** (followers / replies / profile visits / clicks — the goal decides the CTA mix) · **audience** · **voice** (the account's tone — posts must sound like the person, never a template) · **current standing** (followers, what worked last week — if this is a recurring plan, read the last `x-audit.md` + day-7 review and pivot from it). Lock the goal — it decides which posts convert.

### Stage 2 — Research what's working on X right now
If `video-product-pipeline` is installed, run `node scripts/trend-hunt.mjs --niche "{niche}" --subreddits "{r1},{r2}" --geo US`; web-research X trending + the niche's top posts from the last week (which hooks got replies, which payoffs got shared). **Freshness rule:** nothing older than ~14 days. Then pick hook formulas from `templates/post-hooks.md` per post (ONE formula per hook post).

### Stage 3 — Write the content plan → `content-plan.json`
The creative contract the script enforces:
- `goal` (the growth goal) · `niche` · `audience` · `voice` · `cadence` (posts/day) · `pillars[]` (≥ 3, each a content pillar) · `kpis` (followers / replyRate / quotes / visits / conversion targets)
- `posts[]` — ≥ 7 posts (one week), each with `text` + `role` (`hook` / `value` / `story` / `proof` / `cta` / `loop`) + `pillar` (which pillar it feeds). **Every post is a 500–800 char top-creator micro-essay** — hook line ≤ 100 chars opening a loop, then story/context, ≥ 2 bullets, payoff, CTA, with line breaks. Follow the fluff rule; **zero hashtags**.
- The MIX is the series: ≥ 1 hook + ≥ 1 value + ≥ 1 story/proof + ≥ 1 cta/loop, every pillar fed.

### Stage 4 — Assemble + validate → `content-plan.md` + `posts.md` (automated, exit 1 on bad plans)
```bash
node scripts/post-writer.mjs --plan content-plan.json --out content-plan.md
```
The script validates: zero hashtags (a single `#` fails) · **every post inside the 500–800 char window** with a valid role + a real pillar · **hook line ≤ 100 chars** · **top-creator format (≥ 3 lines, ≥ 2 bullets — never a wall of text)** · ≥ 7 posts · the story-spine mix (hook/value/story-or-proof/cta-or-loop present) · every pillar fed · anti-fluff + bait-spam blocklists. **Exits 1 on any FAIL** and writes nothing. On clean it writes `content-plan.md` (goal, KPIs, pillars, cadence table, engagement schedule, day-7 review) + `posts.md` (the drafted copy, role/pillar/char annotations).

### Stage 5 — Write the engagement schedule (inside the plan)
The reply-first hour (reply to every reply within 60 minutes of each post), the quote-post strategy (3–5 niche quote posts per day, one sharp line each), DM follow-ups that match the day's CTA, and follow/unfollow hygiene — from `templates/growth-rituals.md`. The posts get the reach; the replies compound it; the WEEKLY series loop turns it into followers.

### Stage 6 — Audit harness (automated checks + x-auditor subagent, before delivery)
**Step 6a — run the automated audit harness:**
```bash
node scripts/audit-x.mjs --pack <plan-folder> --out x-audit.md
```
`audit-x.mjs` scans the pack and checks everything a script can: posts.md (≥ 7 posts, **every post inside the 500–800 char window**, hook lines ≤ 100, **top-creator format: ≥ 3 lines + ≥ 2 bullets**, roles valid, **zero hashtags**, story-spine mix, pillars fed, fluff + bait blocklists) and content-plan.md (growth rails stated, cadence, engagement schedule, KPIs). Writes `x-audit.md` (automated verdicts + scorecard scaffold). **Exit 1 on any FAIL.**

**Step 6b — spawn the x-auditor subagent** — a FRESH subagent (never self-audit) with the exact brief from `templates/x-auditor-brief.md`: reads `x-audit.md` + all pack files, completes the **growth-plan worthiness scorecard** (10 criteria, /50 — **≥ 35 = worth running**, with verdict bands), makes the creative judgment calls the script can't (hook pull, value density, series feel, CTA fit for the goal, voice consistency), and signs **PASS / FIX NEEDED** with per-post fixes.

**Step 6c — fix loop.** Any FAIL (or an auditor-flagged WARN) → fix `content-plan.json` → re-run `post-writer.mjs` + `audit-x.mjs` → re-submit to a fresh auditor. **Nothing is delivered until the auditor signs off PASS.** The `x-audit.md` ships with the pack.

## Production checklist

- [ ] Mode detected: **new plan** vs **continuation** (read the last day-7 review + audit → pivot from it)
- [ ] Niche locked to ONE · growth goal locked (followers / replies / visits / clicks — decides the CTA mix)
- [ ] Voice captured (the account's tone — no template-speak)
- [ ] **Expert research ran** — `trend-hunt.mjs` or web research; hooks from the last ~14 days of what's working
- [ ] **Zero hashtags** in every post — `post-writer.mjs` + `audit-x.mjs` exit 1 on any `#`
- [ ] ≥ 7 posts drafted, every post **500–800 chars** (top-creator micro-essay: hook line ≤ 100 → story → ≥ 2 bullets → payoff → CTA, ≥ 3 lines with breaks)
- [ ] Story-spine mix complete: ≥ 1 hook + ≥ 1 value + ≥ 1 story/proof + ≥ 1 cta/loop
- [ ] ≥ 3 pillars, every pillar fed by posts; cadence ≥ 1 post/day
- [ ] Fluff + bait-spam blocklists clear
- [ ] Voice matches the account (no template-speak)
- [ ] `post-writer.mjs` ran clean (exit 0) → `content-plan.md` + `posts.md`
- [ ] Plan ships: goal + KPIs + cadence table + engagement schedule (reply-first hour, quote posts, DM rules) + day-7 fix loop
- [ ] **Audit harness run:** `audit-x.mjs` → automated checks — exit 0
- [ ] **X-auditor subagent** (fresh eyes) completed the growth-plan worthiness scorecard (/50 ≥ 35) and signed **PASS / FIX NEEDED** in `x-audit.md`
- [ ] Delivery: `content-plan.md` + `posts.md` + `x-audit.md`
