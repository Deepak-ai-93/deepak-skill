# Post hooks & the top-creator format — reference for x-growth

Every post is a **500–800 char micro-essay in the top-creator format**: the first line (≤ 100 chars) opens a loop, the middle escalates and lists, the last line pays off and converts. **Zero hashtags anywhere** — the copy carries the reach.

## The top-creator post format (the rail — enforced by the scripts)

The accounts that actually grow on X post scannable micro-essays, not 280-char throwaways. This is the format the scripts FAIL without:

```
[HOOK LINE — ≤ 100 chars, opens a loop]
                                   ← line break after the hook (always)
[story / context — 1–3 short lines, each 1–2 sentences, with breaks]
- [bullet 1 — one specific point, a number, a name]
- [bullet 2 — escalates]
- [bullet 3 — the twist or the counterintuitive one]     ← ≥ 2 bullets required
[payoff — the aha the hook promised, quotable on its own]
[CTA / loop — follow, save, DM, "part 2 next week"]
```

Rules of the format:

- **500–800 chars total.** Under 500 = too thin to earn a full read; over 800 = the feed truncates and the payoff dies. The scripts exit 1 outside the window.
- **Hook line ≤ 100 chars** — the FIRST LINE is the scroll-stopper. Cut qualifiers until it fits.
- **≥ 3 lines with breaks** — a wall of text is a FAIL. Break every 1–2 sentences.
- **≥ 2 bullet points** ("- " or "• ") — the list format is what makes the post skimmable and quote-able.
- **Payoff + CTA in the last 2 lines** — the loop closes, then the ask lands.

## Hook formulas (for the FIRST LINE of any post)

| Formula | Mechanism | Template | Example |
|---|---|---|---|
| **Curiosity gap** | Hide the payoff, promise the reveal | "Nobody talks about the [X] that actually [Y]." | "3 pricing mistakes that quietly killed my last SaaS." |
| **Contrarian / pattern break** | Attack a belief the audience holds | "Everything you've heard about [X] is wrong." | "Churn isn't your product's fault. It's your pricing page." |
| **Results-first** | Lead with the win, hide the how | "How I went from [X] to [Y] in [time]." | "I went from 0 → 40k followers. This is what actually moved the needle." |
| **Specific number / list** | Number it, tease the outlier | "[N] [things] — item [K] is the one everyone gets wrong." | "5 pricing mistakes — the third one is the one founders defend the loudest." |
| **Pain / loss aversion (PAS)** | Name the pain, promise relief | "Stop [pain]. Instead, [one move]." | "Stop losing trial users at signup. One page change fixed it." |
| **Story tease** | Start mid-scene, cut to black | "It was 11pm when the invoice arrived…" | "The client quit in week 2. Here's what I learned." |
| **Pattern interrupt** | Break the scroll with an absurd-but-true stat | "[shocking specific] — and nobody screenshots it." | "We lost $12,400 to a button nobody told us about." |

## Post roles (the plan's post mix — the WEEK is the series)

| Role | What it does | Rule |
|---|---|---|
| **hook** | Pure scroll-stop attention play | First line ≤ 100 chars, ONE formula, opens a loop the post closes |
| **value** | Teaches something specific | The bullets teach — one idea, specific moves, no recycled advice |
| **story** | Personal experience / client story | Mid-scene start, a twist, a real number in the payoff |
| **proof** | Results, screenshots, data | Evidence the payoff can be screenshot/cited |
| **cta** | Conversion ask | Clear, specific, matches the goal (follow / link / DM) |
| **loop** | Serial ender / series bait | Chains into the next post or the account ("Part 2", "next week") |

## Rules

- **Zero hashtags.** A single `#` fails the plan (`post-writer.mjs` and `audit-x.mjs` exit 1). X growth is copy-first — hashtags read as spam and kill the native feel.
- **One micro-story per post.** Open a loop in the first line, pay it off by the last line. Every post is complete alone — no "follow for part 2" inside a post that teaches nothing.
- **The week is the series.** Mix hook → value → story/proof → cta/loop across the week. That mix (not one viral post) is what makes the account worth following.
- **Fluff rule:** every line either raises the question, raises the stakes, or pays off. If a line can be deleted without losing the story, delete it.
