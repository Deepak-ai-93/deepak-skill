# Thread formulas — reference for x-threads-engagement

Pick ONE hook formula per thread. The hook is tweet 1 (≤ 100 chars) and it MUST open a loop the thread closes.

## Hook formulas

| Formula | Mechanism | Template | Example |
|---|---|---|---|
| **Curiosity gap** | Hide the payoff, promise the reveal | "Nobody talks about the [X] that actually [Y]." | "3 pricing mistakes that quietly killed my last SaaS." |
| **Contrarian / pattern break** | Attack a belief the audience holds | "Everything you've heard about [X] is wrong." | "Churn isn't your product's fault. It's your pricing page." |
| **Results-first** | Lead with the win, hide the how | "How I went from [X] to [Y] in [time]." | "I went from 0 → 40k followers. This is what actually moved the needle." |
| **Specific number / list** | Number it, tease the outlier | "[N] [things] — #[K] is the one everyone gets wrong." | "5 pricing mistakes — #3 is the one founders defend the loudest." |
| **Pain / loss aversion (PAS)** | Name the pain, promise relief | "Stop [pain]. Instead, [one move]." | "Stop losing trial users at signup. One page change fixed it." |
| **Story tease** | Start mid-scene, cut to black | "It was 11pm when the invoice arrived…" | "The client quit in week 2. Here's what I learned." |
| **Pattern interrupt** | Break the scroll with an absurd-but-true stat | "[shocking specific] — and nobody screenshots it." | "We lost $12,400 to a button nobody told us about." |

## Thread structures (pick the one that fits the story)

| Structure | Beats | Best for |
|---|---|---|
| **Listicle** | hook → #1 → #2 → #3 → payoff → CTA | "5 mistakes", "3 rules" — save-bait |
| **Story / confession** | hook → setup → rising stakes → twist → payoff → CTA | personal experience, client stories |
| **Framework** | hook → the problem → the 3 moves → how they fit → payoff → CTA | "the system" content, teaching |
| **Hot take** | hook (contrarian) → evidence 1 → 2 → 3 → payoff → CTA | opinions, debate bait |
| **Teardown** | hook → what they did → what it cost → the lesson → payoff → CTA | case studies, screenshots |

## Rules

- **Hook ≤ 100 chars.** If it doesn't fit, it's not the hook — cut the qualifiers.
- **5–9 tweets total.** Under 5 = not a thread; over 9 = nobody reads tweet 9.
- **One idea per tweet.** A tweet that makes two points becomes two tweets.
- **The payoff tweet is the "aha"** — the moment the hook's promise lands. It goes BEFORE the CTA.
- **The CTA/loop tweet ends the thread** — a serial hook ("Follow for part 2", "I'll post the template next") or a save/DM ask. Never end on the payoff.
- **Fluff rule:** every tweet either raises the question, raises the stakes, or pays off. If it can be deleted without losing the story, delete it.
